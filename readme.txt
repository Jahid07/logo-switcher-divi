This plugin will add a option in Divi theme customizer to upload logo.

== Description ==
Divi logo switcher will add a new option in your Divi theme customizer> Header And Navigation> Fixed Navigation to upload your logo that will show when you scroll down the page.

> Requires
> [Divi WordPress theme](https://www.elegantthemes.com/)
> Tested with WordPress 7.1.4, Divi 4.27.9, and Divi 5.17.0 using native Divi headers.

= Features =
1. Add an option to upload your logo at theme customizer 
2. Work with divi logo height
3. No coding required

== Installation ==
Through Dashboard

1. Log in to your WordPress admin panel and go to Plugins -> Add New
2. Type **Divi logo switcher** in the search box and click on search button.
3. Find Divi logo switcher plugin.
4. Then click on Install Now after that activate the plugin.
5. Click on setting button & add your logo form theme customizer.

Installing Via FTP

1. Download the plugin to your hardisk.
2. Unzip.
3. Upload the "logo-switcher-divi" folder into your plugins directory.
4. Log in to your WordPress admin panel and click the Plugins menu.
5. Then activate the plugin.
6. Click on setting button & add your logo form theme customizer.
